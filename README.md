# FocusEnglish 学习岛

手机浏览器直接打开的英语学习工作台。主屏幕图标可进入每日单词、句子和继续学习；完整真题、听力和词典位于学习页。联网学习无需导入压缩包。

此仓库保留网站静态文件，学习记录保存在各自设备，不上传到仓库。首次迁移通过声明的 SHA-256 和字节长度校验每一个资源，成功后提交到 site/，后续发布使用仓库中已保存的文件。

在 Settings → Pages 中将 Source 设为 **GitHub Actions**。Actions 中的 Publish FocusEnglish 成功后，使用部署结果给出的真实公开地址。仓库地址用于管理文件，不是手机学习入口。

已有手机记录不会自动跨域迁移。更换网址前，可在原学习页的 Library 或“离线与安装”中导出备份，再在新网址恢复同一格式的备份。

网站内容及原有许可、词典归属说明保留在 site/ 中。物理 iPhone 安装、存储空间和播放行为需要设备实测。
